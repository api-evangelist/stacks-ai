StackAI (Stack AI, Inc.) is an enterprise AI agent platform that lets teams build, deploy, and govern no-code agentic workflows at scale. Its visual Workflow Builder chains LLMs, knowledge bases, connections, and logic nodes into production agents that can be deployed as a REST API, chat assistant, form, or batch job. The public StackAI API runs deployed flows, manages Knowledge Bases and their file resources (upload, index, sync, cursor-paginated listing), and reads flow-run analytics. The platform targets regulated industries with SOC 2 Type II and ISO 27001 certifications, RBAC/SCIM governance, and multi-tenant, VPC, and on-premise deployment options. Backed by Lightspeed Venture Partners.

**Areas:** Company · Artificial Intelligence · Agents · LLM · No-Code · Automation · Workflows · RAG · Knowledge Base · Enterprise

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages.
